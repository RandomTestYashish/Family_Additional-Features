# Family_Additional Features

Working HTML prototype of the Figma page **Family_Additional Features** (file `rGZTE0UxCKIhtcJ9Em2QNn`, node `81564:168380`, section "Manager's view").
Built on the 375 × 812 frame; desktop shows a phone frame, phones scale it to full width.

Open `index.html` (no build step). Flow:
- **Send Reminder** on any benefit card → "Reminder sent successfully!" popup → **Ok, Done** → that button turns grey with a tick.
- **Your Family Benefits → View All** → "Remind your family members" sheet; chips filter (Entertainment, Medicine…); ✕ or tapping outside closes.
- **Family Members → Harshit Vig** → prepaid Service Detail; back arrow returns.
- Pack cards, household tiles, safety report and banners scroll sideways.

`figma/` holds the reference renders used for the visual check. `?shot=home|detail|sheet|ent|modal&y=0` renders a state for comparison.
